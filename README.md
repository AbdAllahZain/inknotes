# حبر · InkNotes

تطبيق أندرويد (React Native + Expo) يشبه Samsung Notes: ملاحظات بخط اليد + فتح ملفات PDF والكتابة عليها وتصديرها.

## المميزات
- **ملاحظات**: صفحات متعددة (بيضاء / مسطّرة / مربعات / نقاط)، تراجع وإعادة، حفظ تلقائي.
- **PDF**: استيراد أي ملف، عرض حاد عند التكبير، كتابة وتمييز ورسم أشكال ونصوص فوقه، ثم **تصدير PDF جديد** تُدمج فيه الكتابة كرسم vector.
- **الأدوات**: قلم، قلم حبر (حساس للضغط)، رصاص، تمييز (Multiply فلا يغطي النص)، ممحاة (تحذف الخط كاملاً)، أشكال (خط، سهم، مستطيل، دائرة)، نص (يدعم العربية RTL)، تحريك.
- **تكبير/تحريك**: قرص بإصبعين، تمرير بقصور ذاتي، ملاءمة العرض.
- **رفض راحة اليد**: من القائمة ⋮ فعّل «القلم فقط للكتابة»، فيصبح الإصبع للتمرير والتكبير فقط.

## كيف تحسّن الكتابة على الأجهزة الضعيفة؟ (`src/ink/engine.ts`)
1. **فلتر One-Euro** على نقاط اللمس: يزيل رجفة شاشات اللمس الرخيصة عند البطء، ولا يُحدث تأخيراً عند السرعة.
2. **محاكاة الضغط من السرعة** حين لا يوجد حساس ضغط (بطيء = أسمك، سريع = أنحف)، فيبدو الخط كأنه بقلم حقيقي.
3. **منحنيات Bézier** بدل الخطوط المستقيمة، وحواف مستديرة.
4. **الأجهزة القوية**: عند اكتشاف قلم (S Pen وغيره) يُستخدم الضغط الحقيقي ومعاملات تنعيم أخف لأقل تأخير.
5. الرسم الحي يتم على UI thread (Reanimated + Skia) فلا يتأثر بحمل JavaScript.

للضبط: عدّل `PRESETS` في `src/tools.ts` (`fingerCutoff` أقل = أنعم وأبطأ استجابة، `penCutoff` للقلم، `gain` تأثير الضغط).

## بناء ملف APK

> التطبيق يستخدم وحدات native (Skia وغيرها) فلا يعمل داخل Expo Go؛ يلزم بناء APK.

### الطريقة 1 — GitHub Actions (بدون تثبيت أي شيء على جهازك)
1. أنشئ مستودعاً على GitHub وارفع محتويات هذا المجلد.
2. افتح تبويب **Actions** ← **Build Android APK** ← **Run workflow**.
3. بعد ~10–15 دقيقة نزّل الملف من **Artifacts** (`InkNotes-apk`) وثبّته على الهاتف.

### الطريقة 2 — EAS Build (سحابي)
```bash
npm install
npx eas-cli login
npx eas-cli build -p android --profile preview   # ينتج ملف APK
```

### الطريقة 3 — محلياً (Android Studio + JDK 17)
```bash
npm install
npx expo prebuild --platform android
cd android && ./gradlew assembleRelease
# الناتج: android/app/build/outputs/apk/release/app-release.apk
```
ملف الـAPK موقّع بمفتاح debug، يصلح للتثبيت المباشر؛ للنشر في Google Play أنشئ مفتاحاً خاصاً.


## الميزات الجديدة (الإصدار 7)
- **تحديد (Lasso):** ارسم دائرة حول الكتابة أو اضغط على عنصر لتحديده، ثم **حرّكه** بالسحب أو **كبّره** من أحد الزوايا، أو انسخه أو غيّر لونه أو احذفه.
- **تثبيت الأشكال:** أثناء الرسم بالقلم أو التمييز ثبّت القلم نصف ثانية في آخر الخط فيتحول إلى خط مستقيم أو دائرة أو مستطيل. (في الخط المستقيم يمكنك مواصلة التحريك لضبط طرفه.)
- **إدراج صور** من الجهاز (زر «صورة»)، ثم تحريكها وتكبيرها بأداة التحديد. تُصدَّر ضمن PDF.
- **مسطرة:** زر «المسطرة»؛ اسحبها بإصبع، وأدرها بإصبعين، وارسم بجوار حافتها فيصبح الخط مستقيماً. تدرّجاتها بالسنتيمتر.
- **إدارة الصفحات (حتى في PDF):** شبكة صور مصغّرة لكل الصفحات: فتح، نقل، نسخ، إدراج صفحة بعدها (بأي نوع ورق)، حذف. التصدير يتبع الترتيب الجديد.
- **تنقل سريع:** مقبض على حافة الشاشة اليمنى (يظهر عند 4 صفحات فما فوق) للسحب بين الصفحات، وأزرار السابق/التالي، والضغط على رقم الصفحة للانتقال لصفحة محددة، وشبكة الصفحات.
- **مجلدات ووسوم** في الشاشة الرئيسية، مع بحث يشمل الوسوم.
- **تصدير صفحة كصورة** PNG، أو كل الصفحات كصور في ملف ZIP (حتى 40 صفحة).
- **نسخة احتياطية واستعادة** من ⚙ الإعدادات: ملف ZIP واحد، والاستعادة تضيف نسخاً ولا تستبدل شيئاً موجوداً.
- **وضع داكن** (حسب النظام/فاتح/داكن) وأوراق جديدة: كورنيل، موسيقى، صفراء، داكنة (الحبر الأسود يتحول تلقائياً إلى فاتح على الورقة الداكنة).
- **قفل التطبيق بالبصمة أو قفل الشاشة** من ⚙ الإعدادات.

## اختبار سريع
```bash
npm test      # محرك الرسم، الهندسة، السجل، النسخ الاحتياطي، EXIF، وترتيب worklets
npm run typecheck
```

## بنية المشروع
```
src/ink/engine.ts        تنعيم + ضغط + توليد حدود الخط (worklets)
src/ink/render.ts        رسم Skia + تحويل النص لصورة عند التصدير
src/editor/EditorCanvas  اللمس والقلم والتكبير والتمرير
src/editor/PageLayer     ورقة الصفحة أو صورة PDF + الحبر
src/services/storage.ts  الحفظ والاستيراد وذاكرة صور الصفحات
src/services/exporter.ts إنشاء PDF النهائي (pdf-lib)
patches/                 تعديل صغير على react-native-pdf-thumbnail لعرض PDF بدقة عالية
```

## حدود معروفة
- ملفات PDF المحمية بكلمة مرور غير مدعومة.
- لا يوجد تدوير للعناصر المحددة (تحريك وتكبير فقط).
- النص في PDF المُصدَّر يُدمج كصورة عالية الدقة (لضمان ظهور العربية بشكل صحيح).
